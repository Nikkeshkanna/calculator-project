# Calculator Project

## Overview

A simple calculator built using HTML, CSS, and JavaScript. This project performs basic arithmetic operations such as addition, subtraction, multiplication, and division.

## Features

* Addition (+)
* Subtraction (-)
* Multiplication (*)
* Division (/)
* Clear button (C)
* Error handling for invalid expressions
* Responsive grid-based button layout

## Technologies Used

* HTML
* CSS
* JavaScript

## Project Structure

calculator-project/

├── index.html

├── index.css

└── README.md

## How to Run

1. Download or clone the repository.
2. Open `index.html` in your web browser.
3. Use the calculator to perform calculations.
